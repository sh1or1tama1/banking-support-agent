Intelligent Banking Customer Support Agent

A Comparative Study of Intent Classification and Grounded Response Generation

Project Goal

Build a banking customer support agent and compare different NLP and LLM methods to find more accurate, reliable, and grounded solutions.

Data

Bitext Retail Banking Dataset
≈ 25,545 Q&A pairs
26 customer intents
9 business categories

Research Questions

  • Does a transformer model (BERT) perform better than a traditional NLP model for intent classification?
  • Can an agentic RAG (multi-step retrieval and answer validation) generate more reliable, evidence-grounded responses than a naive RAG?

System Overview

Customer Query
“I lost my credit card. What should I do?”

Task 1:  Intent Classification

Identify the customer’s banking intent
Baseline
TF-IDF + Logistic Regression
Challenger
Fine-tuned BERT

Task 2: Response Generation

Generate a helpful, grounded and reliable response
Baseline
Naive RAG
Retrieve top-k oncedense retrieval
Generate onceLLM + retrieved context
Reference
Direct LLM
no retrieval · lower bound
Challenger
Agentic RAG (LangGraph)
Bounded loops: ≤ 2 retrieval rounds · ≤ 1 revision
Output: Reliable Banking Support Response
“Please contact your bank to report the lost card …”

Evaluation

Intent ClassificationAccuracy, Macro F1
Response QualityRelevance, Completeness, Clarity (human evaluation)
ReliabilityUnsupported claim rate, Error rate, Reasonable escalation
EfficiencyInference latency, Token usage, Cost

Expected Deliverables

  • Two intent classification models
    (TF-IDF + LR, BERT)
  • Two response generation methods
    (Naive RAG, Agentic RAG) + Direct LLM reference
  • Comparative experimental results and analysis
  • A Streamlit demo (interactive banking chatbot)
  • Final report and presentation
